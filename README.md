# 🧩 DS-OJ · 数据结构在线判题系统

面向**数据结构**课程与算法自学的在线判题（Online Judge）系统。
题库按知识点组织，每道题都配有完整题面、样例、多组测试数据与 C++ 参考解；
每个知识点还配有**题型清单**与**方法总结**，可直接当复习提纲；
支持在线编辑、编译、运行与自动判题。

> **当前状态**：本地版本已完整可用（**307 道题**、2062 个测试点全部校验通过；
> 判题引擎端到端测试 **313/313** 通过；**8 份知识点总结**共 54 种题型、47 个方法模板）。
> 公网部署方案见 [部署指南](deploy/DEPLOY.md)。

## 🚀 快速开始

### 1. 环境要求

- **Python 3.9+**
- **C++ 编译器**（三者任一，程序会自动探测）：

  | 编译器 | 说明 |
  |---|---|
  | **MinGW-w64 / TDM-GCC** | 推荐。安装后将 `bin` 目录加入 `PATH` |
  | **Visual Studio 2022** | 勾选「使用 C++ 的桌面开发」工作负载即可，无需配置环境变量 |
  | **LLVM / Clang** | 安装 `clang++` 并加入 `PATH` |

### 2. 安装依赖

```bash
pip install -r requirements.txt
```

### 3. 校验题库（可选，但推荐）

确认编译器就绪、且全部测试数据与参考解一致：

```bash
python scripts/validate_problems.py
```

预期输出：`通过 39 / 39 道题目`。

### 4. 启动

```bash
streamlit run app.py
```

浏览器打开 **http://localhost:8501** 即可开始答题。

## 📖 使用说明

### 做题流程

1. 左侧筛选（知识点 / 难度 / 标签 / 关键字）找到题目
2. 阅读题面与样例，在编辑器里写 C++ 代码
3. 点 **▶ 运行** 用右侧自定义输入快速调试
4. 点 **🚀 提交判题** 跑全部测试点，右侧显示判决与逐点结果
5. 在 **📝 提交记录** 里回看历史提交与代码

### 知识点总结

侧边栏 **📘 知识点** 是独立的学习/复习入口。每个知识点包含四个标签页：

| 标签页 | 内容 |
|---|---|
| **📋 题型清单** | 每种题型的**识别信号**（看到什么特征该想到它）、**核心思路**、**复杂度**、**易错点**，并直接链接到对应题目 |
| **🛠 方法总结** | 关键技巧与可复制的 **C++ 模板代码**（双指针、单调栈、单调队列、并查集、KMP、Dijkstra、背包…） |
| **📊 复杂度对照** | 该知识点常见操作/算法的时间复杂度与适用场景对照表 |
| **✅ 复习要点** | 考前自查清单，逐条确认是否掌握 |

在题目详情页顶部，也会显示该题**所属的知识点与题型**，方便顺着题型补漏。

> 题型清单里的题目链接是双向的：从题型可以跳到题目，从题目也能回到知识点。

### 判决含义

| 判决 | 含义 | 常见原因 |
|---|---|---|
| **AC** | 通过 | 全部测试点输出正确 |
| **WA** | 答案错误 | 逻辑有误或输出格式不符 |
| **TLE** | 超时 | 算法复杂度过高 / 死循环 |
| **MLE** | 超内存 | 数组开得过大 |
| **RE** | 运行时错误 | 越界、除零、空指针、栈溢出 |
| **CE** | 编译错误 | 语法错误，看编译输出 |
| **OLE** | 输出超限 | 输出量过大，可能有死循环 |

### 输出比对规则

判题采用**宽松比对**，避免格式差异造成误判：

- ✅ 忽略**行尾空白**（空格、制表符）
- ✅ 忽略**文末多余换行**
- ❌ 不忽略行内 token 的顺序与个数

所以不必纠结末尾换行，但数字的顺序和数量必须完全正确。

## ➕ 添加新题目

题库为纯 JSON 文件，一题一个文件，放在 `oj/data/problems/<分类>/<题目id>.json`。

### 推荐做法：用生成脚本

手写测试数据极易出错。项目提供了生成框架，让**测试输出由参考解程序化生成**：

```python
# scripts/generators/gen_mycategory.py
from genkit import build_tests, finalize

def solve(text: str) -> str:
    """参考解（Python 版，与 C++ 参考解算法一致）。"""
    nums = [int(x) for x in text.split()]
    return f"{sum(nums)}\n"

specs = [
    ("样例 1", "1 2 3", 10),
    ("边界情况", "0", 15),
]
tests = build_tests(specs, solve)   # 输出自动来自 solver，不可能写错

problem = { "id": "my-problem", "title": "...", "tests": tests, ... }
finalize(problem, OUT_DIR / "my-problem.json")
```

`finalize()` 会强制让 `samples` 从 `tests` 中标记为 `sample` 的测试点复制，
**杜绝题面样例与判题数据不一致**。

### 添加后务必校验

```bash
python scripts/validate_problems.py -k my-problem
```

## 🌐 部署到公网

两种方式，可同时使用：

| 方式 | 内容 | 说明 |
|---|---|---|

> ⚠️ **重要提示**：Streamlit Cloud 的容器**不保证提供 C++ 编译器**，

> - 用 Docker 部署到自己的服务器（见部署指南的 Docker 方案），或
> - 使用 GitHub Pages 提供题面浏览，判题在本地进行。

## ⚠️ 安全说明

本项目的判题沙箱是**教学/本地开发级**的，提供：

- 子进程隔离与独立工作目录
- 执行超时强制终止
- 内存占用监控与超限终止
- 输出量截断

它**不是**对抗恶意代码的安全沙箱（未使用容器、未限制系统调用与文件访问）。
**公网部署时必须**采用容器化隔离（见部署指南），切勿直接暴露判题接口。
